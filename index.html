How it works

  1. Detect. MediaPipe Hand Landmarker finds 21 points on your hand in every video frame.
  2. Classify. For each finger, the page checks whether the tip is farther from the wrist than its middle joint. The pattern of extended fingers names the gesture. Ratios make it independent of hand size and distance.
  3. Smooth. A majority vote over the last 7 frames stops one bad frame from changing the label.
  4. Act. Each gesture can fire at most once per cooldown, so holding Peace advances one slide per second, not thirty.

A web page cannot press your computer's volume or arrow keys, so Control mode drives the slide deck and audio on this page. The Python desktop version of this project controls the whole system.

Built with MediaPipe Tasks Vision. No frames are stored or sent anywhere.
